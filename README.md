# Market Opportunity Research

Частный статический портал с исследованиями рыночных возможностей для цифровых продуктов. Он объединяет 16 Cursor Canvas-отчётов по B2B и B2C рынкам России и мира, даёт единый каталог, поиск, фильтры и навигацию между исследованиями.

## Локальный запуск

Никакая установка зависимостей не требуется:

```bash
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000/](http://localhost:8000/).

Открывать HTML напрямую через `file://` не рекомендуется: локальный HTTP-сервер обеспечивает одинаковое разрешение относительных путей во всех браузерах.

## Сборка

Страницы воспроизводимо генерируются только средствами Python stdlib:

```bash
python3 scripts/build_static.py
```

По умолчанию скрипт читает канонические исходники из репозитория:

```text
canvas-sources/
```

Другой каталог можно указать явно:

```bash
python3 scripts/build_static.py --source /path/to/canvases
```

Сборщик проверяет, что присутствуют все 16 ожидаемых файлов и нет неучтённых `.canvas.tsx`. При внешнем `--source` он дословно копирует их в `canvas-sources/`; при сборке из канонического каталога не копирует файл сам в себя. Затем import `cursor/canvas` удаляется только из генерируемой HTML-версии, default export преобразуется, и создаётся страница каждого отчёта.

## Архитектура

- `index.html` — каталог-оркестратор с клиентским поиском и фильтрами.
- `reports/<slug>/index.html` — отдельная статическая страница каждого исследования.
- `canvas-sources/` — канонические точные исходники Canvas-файлов; новый рейтинг байт-в-байт совпадает с managed Canvas.
- `assets/canvas-shim.js` — совместимый браузерный слой компонентов и hooks `cursor/canvas`.
- `assets/styles.css` — общие адаптивные стили портала и отчётов.
- `assets/vendor/` — локальные React 18.2.0, ReactDOM 18.2.0 и Babel Standalone.
- `scripts/build_static.py` — воспроизводимая копия и трансформация отчётов.

TSX компилируется в браузере Babel Standalone. Состояние интерактивных фильтров сохраняется в `localStorage` с отдельным namespace для каждого отчёта. Действия, которые в Cursor открывали новый чат, вместо этого копируют или показывают исходный промпт.

## Источники и ограничения

Исходные Canvas-файлы сохранены без изменений; ссылки на внешние источники внутри отчётов остаются активными. Совместимый runtime воспроизводит используемые UI-компоненты и основную интерактивность, но не является пиксель-в-пиксель реализацией внутреннего Cursor Canvas. Графики отрисовываются как доступные HTML/CSS-полосы.

Репозиторий предназначен для приватного хранения исходников. До отдельного размещения на GitHub Pages, внутреннем сервере или другом хостинге он не является публично опубликованным сайтом.
